# Archive — superseded design documents

Kept for history only. Everything here describes the retired Pillars 4–6
implementation that was removed in Step 5B (September 2026): the caucus-group
peer comparison, the seats-versus-nation figure, the state-vote fit, committee
bill flow and Yes/No splits, landmark bills, the alignment score and the 0–100
display. None of it is current, some of it was later found not to hold, and
none of it may be revived (see `HANDOFF.md`, section 5).
